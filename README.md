# Задание 3
Инструкции
Создайте юнит тесты для методов регистрации/авторизации пользователей.
Юнит тесты должны покрывать логику( проверка сложность пароля, уникальности логина, корректность почты и т.д) и работу с базой данных.
Для выполнения данного задания нужно изучить, как можно взаимодействовать с бд во время юнит тестов(посмотрите DataJpaTest и  мокирование)

# Технологии
- - Java 21
- Spring Boot 3.5, Spring MVC, Thymeleaf
- Spring Security + BCrypt
- Spring Data JPA
- файловая база H2
- HTML, CSS и JavaScript для фильтра и мобильного меню

-Регистрация проверяет никнейм, email и пароль, не допускает повторяющиеся данные и сохраняет только BCrypt-хеш. После регистрации можно войти на той же странице. Успешный вход возвращает на главную, где отображается имя пользователя и доступен безопасный POST-выход.
